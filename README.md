# Analyzátor kurzov

Osobná aplikácia na analýzu stávkových kurzov (futbal, NHL, NBA) pre Niké.

- Aplikácia: https://globalpulsemag.github.io/kurzy/
- `picks.json` – denné tipy, ktoré každé ráno aktualizuje naplánovaná analýza.
- Denník stávok, kurzy a nastavenia sa ukladajú len v prehliadači zariadenia (nie sem).

Len 18+. Tipy sú odhady, nie istota.
